# Gotcha 隐私政策 (Privacy Policy)

**最后更新日期：2026年6月**

欢迎使用 Gotcha！我们深知隐私对您的重要性。本隐私政策旨在向您说明 Gotcha 如何处理您的数据。

**1. 数据收集与存储**
Gotcha 是一款主打“纯本地运行”的应用程序。我们**不收集、不存储、也不向任何第三方服务器传输**您的任何个人数据、物品图片或使用习惯。

**2. 核心权限说明**
为了实现应用程序的核心功能，我们需要您授权以下权限：
*   **相机与相册权限：** 仅用于拍摄和选取物品照片，所有照片处理（包括 AI 识别和 OCR 文字提取）均在您的设备本地完成。

**3. 数据同步与备份**
*   如果您开启了 iCloud 同步，您的应用数据将加密保存在您个人的 Apple iCloud 账户中，我们无法访问这些数据。
*   应用内置的 ZIP 导出/导入功能，仅在您的设备本地文件系统中运行，完全由您自主控制。
